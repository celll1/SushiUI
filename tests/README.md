# Tests Directory

This directory contains test scripts and debugging utilities used during development.

## Files

- `check_debug_latents.py` - Debug script for verifying latent cache
- `test_attention_backends.py` - Test script for attention mechanism backends
- `verify_flow_loss.py` - Verification script for flow matching loss
- `verify_sign_fix.py` - Verification script for sign correction in flow matching

## Note

These scripts are for development/debugging purposes only and are excluded from version control.
